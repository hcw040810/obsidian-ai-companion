# 爬取工作流

## 环境

- 用 DrissionPage 接管 Chrome（Chromium() 自动连接正在运行的 Chrome）
- 通过 CDP 获取 cookies：tab.run_cdp('Network.getAllCookies')
- 用 requests + cookies 做 API 请求
- 用 DrissionPage 的 DOM 选择器做页面提取

## 平台状态

| 平台 | 需要登录 | 搜索方式 | 正文获取 | 备注 |
|------|---------|---------|---------|------|
| 小红书 | 是 | DOM提取笔记卡片 | 点进笔记提取详情 | section.note-item |
| 知乎 | 是 | API search_v3 | API articles/{id} | cookies要有z_c0 |
| B站专栏 | 否 | API search/type | API article/view | 正文是JSON ops |
| 微信公众号 | 否 | 搜狗搜索 | 需跳转微信原文 | 标题能拿到 |
| 掘金 | 否 | API search_api | 直接抓页面 | 最稳定 |
| 36氪 | 否 | RSS feed | 文章页反爬 | 正文难抓 |

## 未登录时的操作

1. DrissionPage 打开平台首页
2. 检测登录状态（找"登录"按钮或用户头像）
3. 如果未登录，打开首页让用户手动登录
4. 告诉用户"我在等你登录，登好了告诉我"
5. 用户确认后继续爬取
