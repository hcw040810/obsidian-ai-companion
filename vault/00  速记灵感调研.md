## 可立即执行的点

### yt-dlp（爬视频工具）
- **是什么**: 开源命令行视频下载工具，支持 YouTube、B站、抖音、TikTok、Vimeo 等数千个网站
- **怎么用**: `pip install yt-dlp`，然后 `yt-dlp "视频链接"` 即可下载
- **适合你**: 看到好的视频内容可以下载保存，配合 Obsidian 整理知识
- **行动**: 安装试试，先下载一个 B站视频练手

### Obsidian Web Clipper（自动爬取网页知识）
- **是什么**: Obsidian 官方浏览器扩展，可以一键把网页内容保存到 Obsidian
- **怎么用**: 在 Chrome 商店搜索 "Obsidian Web Clipper" 安装，配置模板后即可使用
- **进阶**: 配合 DeepSeek 等 AI 可以自动提取标签、生成摘要、评价内容价值
- **行动**: 安装 Web Clipper，设一个简单的模板，以后看到好文章直接剪藏

### uki（社交App）
- **是什么**: 年轻人兴趣社交平台，1亿注册用户，主打语音社交和兴趣匹配
- **功能**: 语音房间、即时聊天、兴趣匹配、破冰小游戏
- **适合你**: 如果想拓展社交圈可以试试，但别花太多时间
- **行动**: 下载看看，不感兴趣就删

### N8N 工作流（自动化平台）
- **是什么**: 开源的 AI 原生工作流自动化平台，支持 400+ 应用集成
- **怎么用**: 可以自托管部署，拖拽式构建自动化流程
- **适合你**: 如果你想做自媒体，可以用 N8N 自动化内容发布流程
- **行动**: 先看官方文档了解概念，等有具体需求再上手

### Gbrain（AI知识大脑）
- **是什么**: Y Combinator 总裁 Garry Tan 开源的个人 AI 记忆系统
- **怎么用**: 基于 Postgres + pgvector 构建，让 AI Agent 能读取你的知识库
- **适合你**: 配合 Claude Code 使用，让 AI 成为你的第二个大脑
- **行动**: 看 GitHub 仓库，了解部署方式

### 32Kmcp（MCP工具导航）
- **是什么**: MCP 工具目录网站，收录 1580+ 工具，覆盖 Cursor、Claude Desktop 等
- **怎么用**: 访问 mcphello.com 浏览和筛选 MCP 工具
- **适合你**: 找适合自己工作流的 MCP 工具
- **行动**: 收藏网站，需要时去搜

## 了解后搁置的点

### 孙宇晨
- **是什么**: 波场 TRON 创始人，区块链大佬
- **2026动态**: 发了视频聊健康和 AI，鼓励年轻人投身前沿科技
- **为什么搁置**: 和你当前优先级（考研、毕业）关系不大，但他的观点可以偶尔看看

### 伊拉瑞光塔可以做挂件
- **搜到的是**: 守望先锋游戏角色伊拉锐的光塔攻略，不是你想的那个
- **建议**: 你回忆一下当初想的是什么？可能是某个具体的创意或产品

### 运气实验
- **是什么**: 心理学教授理查德·怀斯曼的"运气四原则"实验
- **核心观点**: 幸运的人不是真的运气好，而是更开放、更注意观察、更乐观、更相信直觉
- **建议**: 这个概念可以记到 MOC 心理与成长里，但不需要马上行动
