# Nat Neurosci | 如何防止记忆混乱？UCLA团队揭示前额叶皮层调控记忆的整合与分离的神经机制

> 来源:
> 爬取时间: 2026-05-12

---


你有没有过这样的体验？昨天发生的事，和今天的经历很容易混在一起；但一周前的事，却很少和今天的新记忆混淆。如果两个场景很像，记忆就会自然串联起来，比如走进一家新咖啡店，却莫名想起常去的那家。大脑到底是用什么规则，决定哪些记忆该连在一起、哪些该分开？


2026年4月28日，美国加州大学洛杉矶分校（UCLA）Alcino J. Silva教授与André F. de Sousa团队在《Nature Neuroscience》上发表研究《The prefrontal cortex controls memory organization in the hippocampus》。

研究发现，腹内侧前额叶皮层（vmPFC）会依据记忆间隔时间和场景相似性被动态激活，通过vmPFC→内侧内嗅皮层（MEC）通路，调控海马体CA1区的神经元重叠与记忆整合——只管控间隔7天的远距离记忆，不影响5小时内的短时记忆。


#

# 大脑怎么判断“该不该把这两个记忆连起来”？

#

团队使用微型荧光钙成像记录小鼠腹内侧前额叶皮层（vmPFC）的神经元活动，让小鼠在不同时间间隔接触不同场景。

结果显示，间隔5小时，不同场景下，vmPFC活动下降；间隔7天，不同场景下vmPFC活动显著上升；同一场景，无论间隔多久vmPFC活动均降低；同时，不同场景间隔7天时，vmPFC神经元重叠更少。

因此，vmPFC 会根据记忆间隔时间和场景相似度，自动调整活跃程度，为记忆整合或分离做准备。


#

# 如果抑制vmPFC，记忆会乱成什么样？

#

团队用化学遗传学抑制vmPFC，然后检测海马CA1区的神经元重叠和记忆整合情况。

结果显示，间隔7天的不同场景记忆，本应分离，却出现异常整合；间隔5小时的记忆整合不受影响。同时，抑制vmPFC会让海马CA1区的神经元重叠率大幅上升，且仅针对场景记忆，不影响其他行为。

这说明，vmPFC 的作用是特异性防止间隔数天的无关记忆错误整合，只管控远距离记忆，不参与短时记忆整合。


#

# vmPFC 通过哪条通路实现调控？

#

团队用全脑c-Fos检测（即刻早期基因，标记被激活的神经元）和交叉病毒策略，追踪vmPFC的下游通路。

结果发现，抑制vmPFC后，它与内侧内嗅皮层（MEC）的功能关联显著减弱。用交叉病毒策略分别抑制vmPFC向MEC、外侧内嗅皮层（LEC）、海马的投射，发现只有抑制vmPFC→MEC通路，会完全重现vmPFC整体抑制的效果。

简单说，vmPFC 是通过直接投射到 MEC 这条通路，向下控制海马的记忆整合。


#

# 这条通路到了海马之后，具体是怎么工作的？

#

团队进一步聚焦到海马CA1区的富含抑制性中间神经元的腔隙分子层（SLM）区域。

研究发现，vmPFC→MEC通路会激活海马CA1区SLM的神经胶质样细胞（NGF）；抑制该通路会降低NGF细胞活性，让旧记忆神经元参与新记忆编码，导致记忆异常整合；激活该通路则能强行分离本应整合的记忆。这揭示了记忆分配受前额叶顶层通路根据过往经验精准调控。

解读：记忆分配（哪个神经元群负责编码哪个记忆）过去被认为主要取决于神经元的固有兴奋性（兴奋性高的更容易被选入记忆印迹）。本研究揭示了一个全新的自上而下的调控机制：前额叶皮层通过vmPFC→MEC通路，激活CA1的NGF抑制性神经元，主动阻止旧记忆神经元被新记忆征用，从而确保远距离记忆的分离。


#

# 全文总结

#

本研明确腹内侧前额叶皮层（vmPFC）会依据记忆间隔时间与场景相似性被动态激活，通过vmPFC-MEC这条特异性通路，调控海马背侧 CA1 区的神经元重叠、神经胶质样抑制细胞活性与记忆分配，最终精准控制间隔 7 天的远距离记忆整合与分离，不干预短时记忆，完整阐明了哺乳动物大脑中前额叶皮层自上而下调控海马记忆组织的核心神经环路与分子机制。

# 小编寄语：

#

如果你曾把两个远距离的相似场景搞混，或者奇怪为什么两个很近的记忆反而没搅在一起，这项研究给出一个答案：

vmPFC正在根据时间间隔决定是否激活vmPFC→MEC通路，间隔太近（几小时内），它放手不管，让海马自行整合；间隔足够远（数天），它通过NGF抑制性神经元，防止旧记忆神经元被新记忆征用。
