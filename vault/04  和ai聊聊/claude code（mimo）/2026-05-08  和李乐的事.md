# 2026-05-08 和李乐的事

## 起因

一开始是我先开始搞的claude code和mimo，后面葛云轩也开始问我（昨天），我也很认真地和他说怎么搞。然后昨天下午他一回来不知道为什么就和李乐([[0214  李乐]])玩得很开心，但是不怎么理我([[0203  孤单]])。晚上看到李乐在搞mimo的事，我顺口问了一句"你也在搞这个啊"，但他反应让我很不舒服，他说"我早就想搞了"，感觉像是在认为我在找他茬、在质问他怎么在学我一样。

主要以前和他相处，他就很喜欢藏东西，但好奇心也强，我很愿意分享，但后面搞得我很难受。最开始是大一的时候物理化学书没有，和他一起上了几节课一起看书做笔记，后面书到了，他不愿意借我书把以前的笔记抄一下，这就让我很难受。

## 今天的事

今天中午去做实验，因为做实验很快就回来了，发现他在厕所。我想着看一下他电脑在干什么([[0215  偷]])（因为真的好奇，但他又不愿意和我说），结果因为没听到冲水声，基本是被抓现行了。他也没太表示，但肯定是知道了。

## 分析

- 我和李乐([[0214  李乐]])之间的问题不是今天这一次，而是好几层东西叠在一起
- 最核心是两件事：一是他习惯藏、我习惯分享，这种不对称从大一物化书就开始了；二是今天被抓到了
- 我不是真的想偷看他电脑里有什么，是想打破那种"他什么都知道你、但你不知道他在干嘛"的不平等感
- 现在难受的点：明明是他先让我不舒服的，结果最后是我被抓到了把柄，主动权全没了

## 关于"是不是我的问题"

- 李乐([[0214  李乐]])那种人——玩得开、人缘好、但习惯性地藏和保留——其实很常见，不是专门针对我
- 别人可能根本不在意他藏不藏，因为别人没那么在乎他
- 反而是因为我把他当朋友、当重要的人，才会对他的"藏"反应这么大
- 不一定是我的问题，更像是我们两个对"亲近"的定义不一样
